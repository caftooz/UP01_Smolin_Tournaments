# Платформа организации киберспортивных турниров (УП.01.01)

Учебная практика по ПМ.01, МДК.01.02. Выполнил: Смолин А. С., группа 4ИСИП-423.
Руководитель: Т.Г. Аксёнова.

## Назначение
Настольное приложение для клуба «Cyber Nexus»: каталог турниров для игроков,
ведение турниров и справочников для администратора, диаграммы и отчёты.

## Технологии
- C#, WPF (.NET Framework 4.8), Visual Studio 2026
- Microsoft SQL Server, Entity Framework 6 (Database First, EDMX)
- System.Windows.Forms.DataVisualization (диаграммы)
- Microsoft Office Interop (экспорт в Word, PDF, Excel)

## Возможности
| Роль | Функции |
| --- | --- |
| Все | Регистрация, вход с капчей после 3 ошибок, смена пароля, смена темы |
| Пользователь (Игрок, Капитан, Судья, Организатор) | Каталог турниров: просмотр, поиск, фильтры, сортировка |
| Администратор | Всё выше + CRUD турниров, дисциплин, форматов, статусов, площадок, пользователей; диаграмма; экспорт .docx/.pdf/.xlsx |

## База данных
27 таблиц по ER-модели ПР2. Интерфейс УП работает с `Tournaments`, `Disciplines`,
`TournamentFormats`, `TournamentStatuses`, `Venues`, `Users`, `Roles`, `AuditLog`;
каскадное удаление затрагивает `Applications`, `TournamentParticipants`, `Stages`,
`Matches`, `MatchMaps`, `PlayerMatchStats`, `Prizes`, `TournamentSponsors`, `Notifications`.
Пароли хранятся как SHA-256 от соли и пароля.

## Запуск
1. В SSMS выполнить по порядку `db/DB_Smolin_Tournaments.sql`
2. Открыть `UP01_Smolin_Tournaments.sln`, в `App.config` в строке подключения `Entities`
   указать свой сервер (`data source=...`).
3. Собрать и запустить (F5). Для экспорта нужен установленный Microsoft Office.

## Структура решения
- `Pages/` — страницы (авторизация, регистрация, каталог, панель администратора, таблицы и формы, диаграмма)
- `Helpers/` — сообщения, хэширование, капча, аутентификация, сохранение в БД, проверка ввода, маски, журнал, темы
- `Helpers/Crud/` — автогенерация таблиц и форм по модели EF: `EntityInfo` (метаданные), `DbSchema` (правила FK и уникальность из БД), `UiMetadata` (подписи, диапазоны, шаблоны), `EntityRules` + `TournamentRules`, `UserRules` (правила сущностей)
- `Models/Partials.cs` — дополнения к классам EF
- `Dictionary.xaml` — стиль по Руководству; `CustomDictionary.xaml` — собственная тёмная тема
- `db/` — скрипты базы данных; `res/` — иконка и шрифты
